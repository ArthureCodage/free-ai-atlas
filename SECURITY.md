# Security policy

## What to report privately

- A vulnerability in code maintained by Free AI Atlas.
- A workflow permission or secret-exposure problem.
- A malicious link or compromised resource entry.
- A reproducible supply-chain risk in a bundled recipe.

Use GitHub's private vulnerability reporting feature when it is enabled. If private reporting is unavailable, contact the repository owner privately through their GitHub profile. Do not open a public issue containing exploit details or secrets.

## Third-party products

Free AI Atlas catalogs but does not maintain third-party services and projects. Report their vulnerabilities through the security policy of the affected vendor or repository. You may separately notify Free AI Atlas so the entry can be marked or removed without publishing exploit details.

## Supported version

Only the current default branch is maintained. No response or remediation deadline is guaranteed, but credible reports will be acknowledged and triaged.

## Secret handling

Never submit live API keys, tokens, cookies, private model URLs, or credentials in an issue, pull request, example, screenshot, or audit report.
