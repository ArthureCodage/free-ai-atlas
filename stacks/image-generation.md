# Local image-generation stack

## Recommended core

- **Workflow engine:** ComfyUI.
- **Models:** obtain from an official publisher or reputable model hub; read every model license.
- **Metadata:** retain prompt, seed, sampler, model hash, and workflow JSON when reproducibility matters.
- **Storage:** keep models, outputs, and temporary files on separate paths when possible.

## Start safely

1. Install the official ComfyUI release.
2. Generate with the default/core nodes before adding extensions.
3. Add one custom node at a time from a reviewed source.
4. Scan model and extension downloads where practical.
5. Do not assume an image model permits commercial work, real-person impersonation, or every content category.

The software can be free while GPU time, electricity, cloud notebooks, and commercial model rights are not.
