# Zero-cost starter stack

This stack gives a newcomer broad capability without installing software or entering a payment card.

| Need | First choice | Why |
|---|---|---|
| General assistant | ChatGPT, Claude, or Gemini | Pick one interface and learn its strengths before collecting more tools. |
| Web research | Perplexity | Sources are visible and easy to open. |
| Model exploration | Hugging Face Model Hub | Learn to read model cards and licenses. |
| Coding prototype | Gemini Developer API or GitHub Models | Both have official developer tooling and free prototyping access. |
| Notebook compute | Kaggle Notebooks or Google Colab | Start without installing GPU drivers. |
| Structured learning | Practical Deep Learning, then the Hugging Face LLM Course | Practical foundations followed by LLM-specific depth. |

## Rules that keep it at $0

- Do not enter a payment card for a “free trial.”
- Turn off optional paid API billing until you deliberately need it.
- Set provider budgets to zero where supported.
- Never bypass quotas with multiple accounts or leaked credentials.
- Export important work; free services do not promise permanent storage or availability.

## Upgrade only when a limit is measured

Write down the exact limitation first: response quality, quota, privacy, latency, context, collaboration, or reliability. Paying without identifying the bottleneck usually creates tool sprawl rather than better work.
