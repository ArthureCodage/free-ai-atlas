## OpenRouter Free Models

- **Idéal pour:** Essayer plusieurs modèles hébergés avec une seule API
- **Gratuité:** Offre gratuite
- **Limites:** L’offre gratuite de base annonce plus de 25 modèles et 50 requêtes par jour; les modèles et la capacité des fournisseurs peuvent changer.
- **Licence:** Variable ou propriétaire
- **Confidentialité:** provider-processed
- **Vérifié:** 2026-08-04 — [source officielle](https://openrouter.ai/pricing)

**À savoir**

- Les modèles gratuits visent l’expérimentation et les faibles volumes, pas une production fiable.
- Les politiques de données et licences peuvent varier selon le fournisseur et le modèle sélectionnés.

- **Idéal pour:** Le chemin le plus simple vers une API LLM locale
- **Gratuité:** Open source
- **Limites:** L’inférence est limitée par la RAM, la VRAM, le stockage, l’électricité et la licence de chaque modèle téléchargé.
- **Licence:** MIT
- **Confidentialité:** local

**À savoir**

- La licence du logiciel Ollama ne remplace pas la licence distincte de chaque modèle.
