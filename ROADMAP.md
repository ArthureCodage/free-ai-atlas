# Free AI Atlas roadmap

Free AI Atlas aims to become the most useful trust-first entry point for people who want to learn, build, and run AI without mandatory spending.

Size alone is not the goal. The project wins when someone can make a safer decision faster and verify every important claim.

## Current milestone — v0.2 Authority Upgrade

- [x] More than 50 evidence-backed resources.
- [x] Beginner, privacy, builder, and advanced discovery paths.
- [x] Side-by-side comparison with account, card, privacy, license, and limit details.
- [x] Machine-readable JSON and CSV exports.
- [x] Generated catalog-health dashboard.
- [x] Daily official-link and evidence-age audits.
- [ ] Recruit the first five recurring external contributors.
- [ ] Reverify every hosted free tier on a rolling schedule.

## v0.3 — Community curation

- Contributor profile and acknowledgements.
- Public category ownership for volunteer curators.
- A weekly evidence-review queue with small, reviewable issues.
- Translation workflow for English and French, then community-maintained languages.
- Monthly release notes covering additions, removals, and changed limits.

## v0.4 — Decision engine

- Shareable filtered URLs.
- Hardware-aware local-model and stack recommendations.
- Exportable personal stack manifests.
- Structured comparisons for hosted APIs and local runtimes.
- Historical changes to pricing, quotas, licenses, and privacy claims.

## v1.0 — Reference infrastructure

- At least 150 current resources with clear evidence ownership.
- Complete beginner-to-production learning paths.
- Public freshness and category-coverage targets.
- Stable versioned data format consumed by external projects.
- Maintainer succession, documented review service levels, and sustainable governance.

## Success measures

We track outcomes rather than vanity alone:

- percentage of entries reverified within policy;
- number of independent recurring contributors;
- time from a reported change to an evidence-reviewed correction;
- categories with an accountable curator;
- external projects using the JSON or CSV data;
- stars, forks, discussions, and returning contributors as secondary signals.

## What we will not do

- accept paid ranking or affiliate links;
- inflate the catalog with duplicate wrappers;
- claim that link reachability proves a free offer;
- silently merge material pricing, privacy, or licensing claims;
- optimize for stars at the expense of accuracy.
