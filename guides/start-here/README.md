## Five words that remove most confusion

- **Model:** the trained system that turns an input into an output.
- **Assistant:** a product that wraps one or more models in a user interface.
- **API:** a way for your code to send requests to a hosted or local model.
- **Local:** inference happens on hardware you control.
- **Open source / open weight:** different concepts. Software can be open source while a model has a custom license. Always inspect both.

## A safe first session

1. Pick one non-sensitive task you already understand.
2. Ask an assistant to produce a first draft, not a final truth.
3. Check names, numbers, links, and quotations yourself.
4. Remove confidential, medical, legal, financial, customer, and employer data unless the service is approved for it.
5. Keep the original material so you can compare what changed.

## Learn the foundations

Recommended order:

1. Learn prompting by doing small, verifiable tasks.
2. Complete the first lessons of [Practical Deep Learning for Coders](https://course.fast.ai/) if you know basic Python.
3. Study the [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1) for transformers, datasets, fine-tuning, and sharing.
4. Run a small local model through [Ollama](../../guides/local-ai/README.md).
5. Build one tiny app against a free API, then switch it to a local OpenAI-compatible endpoint.

## What “free” does not include

Local tools can avoid subscription costs, but your computer, storage, electricity, time, and model-license obligations still exist. Hosted free tiers can change without notice and should not be treated as production service-level agreements.
