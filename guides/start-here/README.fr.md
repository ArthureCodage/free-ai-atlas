# Commencer ici

Tu n’as pas besoin de comprendre les modèles, jetons, GPU ou API pour profiter de l’IA. Commence par ton résultat recherché et ajoute de la complexité uniquement lorsqu’elle résout un vrai problème.

| Ta situation | Parcours recommandé |

## Cinq mots qui enlèvent beaucoup de confusion

- **Modèle :** le système entraîné qui transforme une entrée en sortie.
- **Assistant :** un produit qui présente un ou plusieurs modèles dans une interface.
- **API :** une façon pour ton code d’interroger un modèle local ou hébergé.
- **Local :** l’inférence se déroule sur du matériel que tu contrôles.
- **Open source / poids ouverts :** deux concepts différents. Le logiciel et le modèle peuvent avoir des licences distinctes.

## Une première session prudente

1. Choisis une tâche non sensible dont tu connais déjà le sujet.
2. Demande un premier brouillon, pas une vérité finale.
3. Vérifie toi-même les noms, nombres, liens et citations.
4. Retire les données confidentielles, médicales, juridiques, financières, professionnelles ou de clients.
5. Garde le contenu original afin de comparer les modifications.

## Apprendre les fondations

Ordre recommandé :

1. Apprends à formuler des demandes avec de petites tâches vérifiables.
2. Suis les premières leçons de [Practical Deep Learning for Coders](https://course.fast.ai/) si tu connais Python.
3. Étudie le [cours LLM de Hugging Face](https://huggingface.co/learn/llm-course/chapter1/1).
4. Lance un petit modèle local avec [Ollama](../local-ai/README.md).
5. Construis une petite application avec une API gratuite, puis remplace-la par une API locale compatible OpenAI.

## Ce que « gratuit » ne couvre pas

Les outils locaux évitent des abonnements, mais le matériel, le stockage, l’électricité, ton temps et les licences existent toujours. Une offre cloud gratuite peut changer sans préavis et ne constitue pas une garantie de production.
