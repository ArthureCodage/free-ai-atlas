# Changelog

All notable project changes are documented here.

## Unreleased

- Add more verified resources and translations through reviewed contributions.

## 0.2.0 — 2026-08-04

- Expand the evidence-backed catalog from 20 to 56 resources across 18 categories.
- Add goal-based discovery paths, richer filters, sorting, resource details, and side-by-side comparison for up to three tools.
- Publish deterministic JSON and CSV exports plus a generated catalog-health dashboard.
- Add a public roadmap, data documentation, catalog coverage tests, and stronger daily-audit reporting.

## 0.1.0 — 2026-08-04

- Launch the bilingual Free AI Atlas catalog with 20 evidence-backed resources.
- Add beginner, local AI, privacy, API, image, RAG, coding, and agent guides.
- Add a dependency-free searchable static site.
- Add JSON schema validation, deterministic generation, unit tests, daily link auditing, CI, security scanning, and GitHub Pages deployment.
- Add issue forms, governance, contribution, verification, security, and conduct policies.
