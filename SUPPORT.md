# Support

- Use **Discussions** for questions, setup help, and comparisons once enabled.
- Use the resource proposal form for a new catalog entry.
- Use the changed-offer form when a price, quota, license, or privacy rule changed.
- Use a regular issue for a reproducible repository bug.
- Use private security reporting for vulnerabilities or malicious links.

Free AI Atlas cannot provide account support for listed third-party products. Contact the product's official support channel for billing, access, or service incidents.
