# Contributors

Free AI Atlas is built in public. Every careful verification, correction, translation, guide, design improvement, and code contribution makes the atlas more useful.

## Recognition

- Pull requests are credited through GitHub's contributor graph.
- Material catalog contributions are acknowledged in release notes.
- Repeat contributors can be invited to own a category or verification lane under the governance policy.

## Category owners

Category owners volunteer to review contributions and maintain accuracy for a specific topic area. Owners are listed in the categories they maintain and receive recognition in release notes and the contributor profile section.

To become a category owner, start by contributing 3+ verified resources or corrections in that category, then request ownership through a GitHub issue.
