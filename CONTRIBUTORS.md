# Contributors

Free AI Atlas is built in public. Every careful verification, correction, translation, guide, design improvement, and code contribution makes the atlas more useful.

## Recognition

- Pull requests are credited through GitHub's contributor graph.
- Material catalog contributions are acknowledged in release notes.
- Repeat contributors can be invited to own a category or verification lane under the governance policy.

## First contribution

Choose an issue labeled `good first issue`, improve one claim with an official source, or add one well-scoped resource using the contribution guide. Accuracy matters more than volume.

See [CONTRIBUTING.md](CONTRIBUTING.md) and [GOVERNANCE.md](GOVERNANCE.md) to get started.
